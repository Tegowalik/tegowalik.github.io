Behind the tracks.
How it all works.

Quick answers about the colored track markers, temporary layouts, planning, switch automation, and the motors behind our longest trains.

What do the colored tiles on the track mean?

They mainly identify the track geometry: standard straights, double straights, and curve radii such as R40, R56, R72, R88, and R104.

Historically, some colors also showed which track belonged to which person. That older system is still mixed in, so the colors are useful—but not a perfectly clean one-to-one code.

Can I visit one of the large train track setups?

Unfortunately not. These are temporary builds in private spaces, usually assembled for only a few days and then completely dismantled. The best way to experience them is through the full setup videos and behind-the-scenes posts.

How do you plan these gigantic LEGO train track setups?

I use BlueBrick, a free LEGO layout editor, to plan the track network.

BlueBrick shows the layout in two dimensions. Multi-level routing, bridge heights, slopes, and clearances therefore still require a lot of spatial thinking—and some planning beyond what the software can display.

How do you automate your switches?

The switches use LEGO Powered Up or MINDSTORMS hardware, motors, sensors, and Pybricks code. The open-source LEGO Switch Controller repository includes the code and practical examples.

How do you run such long trains with so many wagons?

We use two Powered Up train motors controlled together from one City Hub. The Pybricks Train Controller repository contains the code and setup guide.
